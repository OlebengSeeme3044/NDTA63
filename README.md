## Overview

This is the codebase produced for the **NDTA63 Data Analysis and Visualization** course.

The project investigates the relationship between **ICT regulatory development** and **cybersecurity readiness in South Africa** using the **ITU ICT Regulatory Tracker** and **Global Cybersecurity Index (GCI)** datasets.

The analysis includes data cleaning, exploratory data analysis, numerical analysis, database operations, SQL queries, and data visualisation.

Written in **Python & SQL**

## Datasets

The project uses two main datasets:

- **ITU ICT Regulatory Tracker** – used to analyse ICT regulatory development over time.
- **Global Cybersecurity Index (GCI)** – used to analyse cybersecurity readiness and its dimensions.

The datasets are stored in the `data/raw/` directory.
